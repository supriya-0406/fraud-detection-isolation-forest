# 💳 Fraud Detection using Isolation Forest

## 📌 Overview

This project detects fraudulent transactions using Isolation Forest, an anomaly detection algorithm.

---

## 🎯 Objective

Identify unusual transactions that may indicate fraud.

---

## 🧠 Model

Isolation Forest

---

## 📊 Dataset

Transaction features:

* Amount
* Time
* Location

---

## ⚙️ Technologies

* Python
* Pandas
* Scikit-learn
* Matplotlib

---

## 🚀 How to Run

pip install -r requirements.txt
python main.py

---

## 📈 Output

* Fraud detection labels
* Visualization of anomalies

---

## 💡 Business Impact

* Reduce financial fraud
* Improve transaction monitoring
* Enhance security systems
